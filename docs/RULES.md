# GameMog rules

The single source of truth for the platform's rules. Each rule is the owner's words, then how
the code reads them, then where that is tested. A change to a rule changes this file first,
and the owner approves the interpretation before it is built.

North star: **the internet, playable.** Prompt → build world → play → share → **Mog**.
AI generates, humans select, winners reproduce. Platform first; movement second.

---

**Constants** (`meta.kartScore`, version 1): `{ version, source: 'measured' | 'inherited' | 'course' | 'minimal', tStar: { racer: s }, tFloor: { racer: s }, karts, laps, gmCap, gmMax, hitsCap: 30, hitsMax: 64, lap, trackSig, physics, world, at }` (and `from`, the parent, when inherited). `trackSig` is the track's signature (`kartTrackSig` in `lib/runtime/kart.js`: 16 hex digits over everything the constants are measured from, the centre line to the centimetre, the road's width and walls, the course on it, the laps and the class; never the looks or the racers), the same string from the race in the browser (`kartState().trackSig`) and from the node sim; Meme Kart's is d90450e9fd3eddee, The Original's the same. `tFloor` is each racer's T\*\_items (rocket speed on the shortest path: 91.276 s for Bull Run, 92.066 for Pepe), the route's plausibility floor. `gmCap` is the coins laid in the race plus every rival's 2 GM purse (134), `gmMax` that plus the luckiest GM Bags (197).

- **Measured at publish**: `npm run publish:world -- <name>` (first-party worlds and `--mog`) runs `measure.mjs` on the world's own track and the kit's own rules (about 15 s, a worker per racer), stores it in the world's meta and rescores its board. A Mog is measured on its own code, never its parent's. If the measurement fails, the course fallback (`courseConstants`: 0.9 x laps x lap / (class top x 1.05 x 1.28 x 1.06), every number low) is stored instead.
- **Any stored game**: `node scripts/kart-score/measure.mjs --game <slug>` measures it, writes `meta.kartScore` and rescores its rows. It runs the world's code in node, so it is the operator's command, for a world you trust.
- **Published from the site** (8 Oct, `publishedKartConstants` in `lib/kart-score.ts`, at `POST /api/games`; the server never runs a creator's code, so the track comes from the creator's test drive of exactly the code published, `report.kart`): (a) a Mog whose drive reports its parent's track signature, laps and class, the parent's constants measured (or inherited) and signed, stores the parent's constants as they are, flagged `inherited` (a racer the parent's table lacks gets the course's time for that lap), so it scores every run exactly as its parent does; (b) else, a lap the drive measured: the course constants from that lap (held to 760 to 1890 m, the runtime's 800 to 1800 and a little either side for hills), flagged `course`; (c) else nothing is stored. A drive of other code counts for nothing, and constants a draft's meta brings are never kept.
- **No constants**: the route and page use the course fallback from the code, flagged `minimal` (the lap from written-out track points, else 800 m, the shortest lap the runtime allows). Scores against `course` or `minimal` constants are low by design: the board, the post panel and the results screen say they are provisional (the results screen names no next tier) until the world is measured; `inherited` counts as measured.
- **Meme Kart's signature on the live rows**: migration `2026-10-09-meme-kart-track-sig` adds `trackSig` to `meta.kartScore` (Meme Kart's and The Original's) and nothing else, only where the row's code is the shipped code (sha256) and its constants were measured on that lap; `node --import ./scripts/ts-resolve.mjs scripts/kart-score/test-mog.mjs` works each signature out again.
- **When the physics change**: `physics` is kart.js's sha1; re-run `measure.mjs` for each kart world (it rescores), then the archetypes and `calibrate.mjs` (below).

**The route** (`app/api/scores/route.ts`, kart branch) never reads the posted score. It recomputes it from the parts with the same file the game carries, and refuses (422) an assisted run, a place outside 1 to `karts`, the wrong laps, a time under the racer's floor or over 30 minutes, GM over `gmMax`, hits over `hitsMax`, a progress outside 0 to 1 (or 1 on a called race). A time under the racer's T\* (but over the floor) is stored hidden, for review. It stores the score, `kos` = enemies hit, `level` = laps, and `est`, `progress`, `racer`, `score_v`, `tier`; it answers `{ ok, score, tier, parts, rank, best, review, source }`, where `rank` is the player's place on the board by their best run and `best` says whether this run is it. Other worlds' scores are unchanged.

### Known limits of v1

- **Players are browsers, not verified humans.** Without accounts, a "player" is an id the browser
  generates for itself. That stops accidents, not fraud. Verified human audiences, which creator
  earnings depend on, need accounts.
- **Distinct players count finished runs**, reported by the game frame; a game's `plays` counter
  counts page loads.
